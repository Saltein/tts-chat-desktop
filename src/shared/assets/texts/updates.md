# Обновление 0.3.3

# Что нового

## Функциональные улучшения
- **Стилизация**
    - Добавлена возможность настроить **закругление** краёв у сообщений

- **Озвучивание сообщений**
    - Новый переключатель: На странице "***Озвучка чата***" добавлен тумблер "***У каждого свой голос***". Если он включён:
        - При первом взаимодействии каждому пользователю назначается **уникальный случайный голос** озвучки.
        - Назначенный голос **«закрепляется» за пользователем** (не сбрасывается при перезапуске).
        - Чтобы получить следующий случайный голос по списку, пользователь должен **написать в чат**: "**!голос**".
