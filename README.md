# TTS Chat Desctop

**TTS Chat Desktop** — это десктопное приложение на базе Electron, которое озвучивает сообщения из стриминговых чатов (Twitch, YouTube, VK Live) с использованием Text-to-Speech, выводить чат и статистику в OBS.

Приложение предназначено для стримеров и контент-мейкеров, которые хотят удобно взаимодействовать с чатом.

## 🚀 Возможности

- 🔊 Озвучивание сообщений из чата (TTS)
    - Локальный сервер озвучки на твоем ПК - нет лимита на озвучивание
    - Возможность добавить пользователей, сообщения которых **будут озвучиваться** в **белый список** или добавить их в **чёрный список**, чтобы из сообщения **не озвучивались**.
    - Заново озвучить сообщение при нажатии на него
    - Пропуск аудио по горячей клавише
    - Озвучивание последнего сообщения по горячей клавише
- 💬 Чат с нескольких платформ в одном окне
- 🎞️ Виджет чата для OBS
- 👁️ Виджет статистики стрима _(количество зрителей и лайков)_ для OBS
- 📺 Поддержка платформ:
    - Twitch
    - YouTube
    - VK Live
- ⚙️ Гибкая настройка внешнего вида
- 🖥️ Удобный UI на React + Redux
- 🔜Система обновления приложения
- 🔄 Подключение/отключение чатов в реальном времени

## 🛠️ Технологии

### Frontend / Desktop:
- Electron — десктопное приложение
- React — интерфейс
- Redux — управление состоянием

### Backend серверов:
- Node.js — серверная логика внутри приложения
- Python — TTS сервер
- Flask — REST API для TTS

### TTS и аудио:
- Silero TTS — нейросетевой синтез речи
- PyTorch — фреймворк для нейронных сетей
- SoundFile, SciPy, NumPy — аудио обработка
- TorchAudio — аудио утилиты

### Коммуникации:
- vklive-message-client — работа с VK Live чатами
- tmi.js — работа с Twitch чатами
- youtubei.js — работа с YouTube чатами
- WebSockets — связь между серверами
- REST API — HTTP эндпоинты

### Системное:
- Subprocess, Threading, Asyncio — системные операции
- Tempfile, AtExit — управление ресурсами

## 📦 Установка

1. Перейдите в раздел [Releases](https://github.com/your-username/tts-chat-desktop/releases)
2. Скачайте последнюю версию приложения:
    - `TTS-Chat-Desktop-Setup-x.x.x.exe`
3. Установите в любую папку
4. После этого появится ярлык на рабочем столе
## ❌❌❌ Приложение не запуститься без обхода блокировки Youtube _(Я в процессе исправления)_ ❌❌❌

### 🧑‍💻 Для разработчиков

1. `git clone https://github.com/Saltein/tts-electron-version.git`
2. `cd tts-chat-desktop`
3. `npm install`
4. ▶️ Запуск
    - В режиме разработки:
        - `npm run dev`
    - Сборка приложения:
        - `npm run build`
    - Запуск собранного приложения:
        - `npm start`
    - Сборка `.exe` файла:
        - `npm run build:electron:win`

#### 🔑 Переменные окружения

Создай файл .env в корне проекта:

```
VITE_TWITCH_BOT_NAME=имя_бота
VITE_TWITCH_BOT_TOKEN=токен_бота

VITE_BASE_URL_API=http://localhost:5001
VITE_BASE_URL_WEBSOCKET=ws://localhost:6789
VITE_BASE_URL_WIDGET=http://127.0.0.1:3030

VITE_GITHUB_TOKEN=токен_гитхаба

VITE_TWITCH_APP_ID=id_приложения_Twitch_Developers_Console
VITE_TWITCH_APP_SECRET=secret_id_приложения_Twitch_Developers_Console

```

### ⚠️ Важно: не публикуй .env в репозитории
